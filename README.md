## 🚀 RECENT Projects (from the last year)

### 🗂️ ERD to SQL: LLM-Powered Diagram-to-Code Tool
*Python · PERN Stack · LLM fine-tuning · WPI · Jun – Oct 2025*

Upload an image of an Entity Relationship Diagram and get executable SQL back. Fine-tuned an LLM on SQL, evaluated it against Yale's Spider 1.0 benchmark, and added an analysis mode that flags mismatches between existing SQL and an ERD. Includes an instructor grading feature and multi-user session sharing.

[Demo](https://esapt2025.vercel.app/imggem)

### 🪞 Magic Mirror: Voice-Driven Multi-Agent System
*Raspberry Pi · Python · Gemini API · ElevenLabs*

A smart mirror (display behind two-way mirror film) you can talk to. A Gemini agent interprets speech and routes each request to a direct API call or a web search, and ElevenLabs narrates the response. A motion sensor turns on a remote night light, using sunrise/sunset times from a weather API.

### 🏥 Hospital Kiosk App
*PERN stack · AWS EC2 · Docker · AWS RDS · WPI · Mar – May 2025*

Led a 10-person team as lead engineer. Features hospital pathfinding, a map editor, service request modules, a voice-activated UI, and a hand-gesture motion map.

### 🌐 Distributed S3-Style Object Storage Simulation
*Go · WPI Distributed Computing Systems*

Simulated storage nodes using goroutines and channels, with heartbeat-based failure detection and quorum-based replication. Tuned timeouts to tell slow nodes from failed ones and debugged race conditions.

### 🦾 2-DOF Parallel Manipulator (Pantograph Mechanism)
*Romi platform · Inverse kinematics · Servo/DC motor control*

Built a two-degree-of-freedom manipulator on a Romi chassis. Implemented inverse kinematics to position a gripper at a target point and wrote the motor control code to drive each joint.
